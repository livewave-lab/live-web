# Coichua 直播間 Demo

用途：確認 TikTok 式手機直播間的方向（版面、互動）。這是展示用 demo，資料全部是假的；正式專案會另外用 Nuxt 3 + TypeScript 建立。

## 怎麼看
直接雙擊 `index.html`，用瀏覽器打開。電腦上建議按 F12 切到手機模式，或把視窗縮窄。

介面照抖音直播的兩種狀態：
- **未進入（滑動瀏覽）**：滿版直式畫面、上方「Following / For You」、底部選單、主播名稱和標題、「Tap to enter live room」按鈕。不能留言、不顯示在線人數、沒有功能按鈕。
- **進入直播間**：上方分頁和底部選單消失；顯示主播、追蹤、觀眾頭像、在線人數、✕ 離開；左下聊天室；底部「Say something…」、表情、數據、愛心、分享。進入後上下滑會直接換到下一個直播間。

操作：
- 滑鼠滾輪或鍵盤 ↑ ↓：換直播間
- 點畫面或按鈕：進入；✕ 或 Esc：離開
- 進入後雙擊畫面：按讚；數據圖示：打開比賽數據面板（對應舊站的各個分頁）

畫布一律是直式 9:16，由主播在 OBS 自己排版：可以放橫向比賽畫面加自己的鏡頭、只放橫向畫面，或只放自己。網站只負責把 9:16 的串流滿版播放。

## 檔案結構
```
demo/
├── index.html        頁面骨架
├── img/logo.png      Coichua logo
├── css/style.css     版面、直播間樣式
├── css/match-sheet.css 比賽數據面板樣式
└── js/
    ├── icons.js      圖示（SVG，仿抖音）
    ├── i18n.js       介面文字（預設英文；中文留給內部檢視）
    ├── mock-data.js  假的直播間、聊天資料
    ├── match-data.js 假的比賽數據（正式版接 TheSports）
    ├── match-sheet.js 比賽數據面板：總覽、陣容、對戰紀錄、近期戰績、積分榜
    ├── stage.js      9:16 畫布佔位：比賽＋主播鏡頭／只有比賽／只有主播（正式版換成騰訊雲播放器）
    └── app.js        未進入／進入直播間兩種狀態、聊天模擬、按讚等互動
```
腳本用一般 `<script>` 依序載入（不用 ES module），所以不需要伺服器，雙擊就能開。
