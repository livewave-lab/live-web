# Coichua 直播間 Demo

用途：確認 TikTok 式手機直播間的方向（版面、互動）。這是展示用 demo，資料全部是假的；正式專案會另外用 Nuxt 3 + TypeScript 建立。

## 怎麼看
直接雙擊 `index.html`，用瀏覽器打開。電腦上建議按 F12 切到手機模式，或把視窗縮窄。

介面照抖音直播的兩種狀態：
- **未進入（滑動瀏覽）**：滿版直式畫面、上方「Following / For You」、底部選單、主播名稱和標題、「Tap to enter live room」按鈕。不能留言、不顯示在線人數、沒有功能按鈕。
- **進入直播間**：上方分頁和底部選單消失；顯示主播、追蹤、觀眾頭像、在線人數、✕ 離開；左下聊天室；底部「Say something…」、表情、數據、愛心、分享。進入後上下滑會直接換到下一個直播間。

操作：
- 滑鼠滾輪或鍵盤 ↑ ↓：換直播間
- 點畫面或按鈕：進入；✕ 或 Esc：離開
- 進入後雙擊畫面：按讚；數據圖示：打開比賽數據面板（對應舊站的各個分頁）

## v9 新增：頁面、登入、比賽資訊（只有前台，資料都是假的）
沒有一般的首頁：**Home 就是直播**（For You），跟抖音一樣。網址用 `#/` 路由，瀏覽器的上一頁可以用。
- **Following**：只顯示追蹤的主播；沒登入顯示「登入後查看」。
- **Schedule `#/schedule`**：日期（昨天～後天）、運動分類、依聯賽分組的比賽卡。
  直播中 → 「Watch」直接進直播間；未開始 → 「Remind me」（要登入）；完場 → 最終比分。點卡片 → 比賽數據面板。
- **Inbox `#/inbox`**：系統通知、主播開播、比賽提醒（要登入）。
- **Me `#/me`**：未登入顯示登入按鈕；登入後顯示暱稱、追蹤數、提醒數、語言切換（English／中文）、登出。
- **＋**：開播只限通過身分驗證的主播（之後做）。
- **登入／註冊**：不做獨立頁，從下方彈出（照抖音）。越南手機號碼 → 6 位數驗證碼 → 設暱稱。
  Demo 驗證碼固定 `123456`，不會真的發簡訊。沒登入可以看、可以滑；留言、追蹤、提醒會先要求登入。
- **直播間比賽資訊**：未進入時主播名稱上方一行比分；進入後上方比分條（點了開數據面板）；
  進球、黃牌、角球等事件每隔一段時間出現在聊天室，比分同步更新（正式版接 TheSports 即時事件）。

## v10 新增：左上選單、右上搜尋、個人主頁（會員／主播）
- **☰ 左上角選單**（側邊抽屜）：未登入時最上面是「登入／註冊」；登入後顯示頭像，以及「追蹤中・正在直播」的主播。下面是消息、觀看紀錄、比賽提醒、賽程、下載 App、語言、設定、幫助、條款、登出。☰ 上的紅色數字是未讀通知。
- **🔍 右上角搜尋 `#/search`**：沒輸入時顯示最近搜尋和熱門搜尋；輸入後即時顯示符合的直播間和比賽，可以直接進直播間或看比賽數據。
- **Me 個人主頁 `#/me`**（右下角）：頭像、名稱、追蹤／粉絲／提醒數、編輯資料、分享主頁；下方分頁是追蹤中、比賽提醒、觀看紀錄。
  - 一般會員：「我的功能」＝消息、提醒、觀看紀錄、成為主播（申請）。
  - 主播：多一區「主播中心」＝開始直播、選擇賽事、OBS 推流金鑰、直播數據、粉絲、主播規範，「我的功能」裡多了收益。主播後台還沒做，按下去只會顯示「之後的版本」。
  - Demo 用：主頁上的黃色按鈕可以在會員和主播之間切換，方便展示。
- **直接打開登入畫面**：網址加 `#/login`。

## v13：桌機首頁 banner
首頁左上改成輪播 banner（`js/banner-data.js` 設定內容，正式版由營運後台管理）。每 5 秒換一張、滑鼠移上去暫停、箭頭和圓點切換。

## v11 新增：桌機版（參考 live.douyin.com）
螢幕寬 1024px 以上自動切換成桌機版；手機和平板維持手機版。
- **左側選單**：logo、下載 App、首頁、追蹤、賽程、消息、我的；底部切換中文／English。
- **上方**：中間搜尋列（按 Enter 進搜尋頁）；右邊下載 App、消息（紅點 3）、開播、登入按鈕（登入後換成頭像）。
- **首頁**：分類（全部／足球／籃球／電競／娛樂／聊天）→ 大的精選直播（直式畫面置中、兩側黑邊）＋右邊「我的關注」和 3 張直播卡 → 「今日賽事」橫向列表 → 「更多直播」卡片牆。
- **直播間 `#/live/編號`**：中間是直播畫面（兩側模糊背景），左上返回＋主播＋追蹤，上方比分條，右側上下切換直播間（也可用鍵盤 ↑ ↓，Esc 返回首頁）；右邊面板＝在線觀眾、比賽卡（點開數據）、聊天室、留言框（沒登入顯示「登入後才能開始聊天」）。
- **登入**：畫面中間的視窗，左邊掃碼登入（App 之後推出）、右邊手機號碼＋驗證碼，照 douyin.com。
- 賽程、我的、消息、搜尋頁和手機版共用，只是放寬置中。
- 新增兩個不綁比賽的直播間（娛樂、聊天），展示三種內容方向。
- 手機版也支援 `#/live/編號`：直接打開該直播間（可以分享直播間連結）。

畫布一律是直式 9:16，由主播在 OBS 自己排版：可以放橫向比賽畫面加自己的鏡頭、只放橫向畫面，或只放自己。網站只負責把 9:16 的串流滿版播放。

## 檔案結構
```
demo/
├── index.html        頁面骨架
├── img/logo.png      Coichua logo
├── css/style.css     版面、直播間樣式
├── css/match-sheet.css 比賽數據面板樣式
├── css/pages.css     賽程、消息、我的
├── css/auth.css      登入／註冊彈窗
├── css/desktop.css   桌機版版面
└── js/
    ├── icons.js      圖示（SVG，仿抖音）
    ├── i18n.js       介面文字（預設英文；中文留給內部檢視）
    ├── i18n-pages.js v9 頁面的介面文字
    ├── schedule-data.js 假的賽程（正式版接 TheSports）
    ├── mock-data.js  假的直播間、聊天資料
    ├── banner-data.js  桌機首頁 banner 內容（v13）
    ├── match-data.js 假的比賽數據（正式版接 TheSports）
    ├── match-sheet.js 比賽數據面板：總覽、陣容、對戰紀錄、近期戰績、積分榜
    ├── stage.js      9:16 畫布佔位：比賽＋主播鏡頭／只有比賽／只有主播（正式版換成騰訊雲播放器）
    ├── auth.js       登入／註冊彈窗（Demo：驗證碼 123456，只存在瀏覽器分頁）
    ├── app.js        未進入／進入直播間兩種狀態、聊天模擬、比賽事件、按讚等互動
    ├── pages.js      底部選單的頁面與路由：賽程、消息、我的（會員／主播功能）
    ├── drawer.js     左上角 ☰ 側邊選單
    ├── search.js     右上角搜尋頁
    ├── desktop.js    桌機版（1024px 以上）：左側選單、上方搜尋、首頁、直播間頁
    └── main.js       啟動
```
腳本用一般 `<script>` 依序載入（不用 ES module），所以不需要伺服器，雙擊就能開。
